# Design assets

Illustration and doodle-accent PNGs shared for the frontend rebuild, with
their original flat-white backgrounds converted to real alpha transparency.
Not wired into any app — just the raw source files.

- `illustrations/` — 22 full illustrations (one per named file, e.g. `19n.png`).
- `doodles/` — 10 hand-drawn accent graphics (circles, arrows, sparkles) in
  the brand colors (lime, periwinkle, forest).
